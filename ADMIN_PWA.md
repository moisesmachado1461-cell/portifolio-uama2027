# UAMA — App administrativo separado

Esta fase mantém o aplicativo público e cria um segundo PWA para a área administrativa.

## Resultado

- App público: **UAMA**
- App administrativo: **UAMA Admin**
- Ícones separados.
- O Admin abre diretamente em `/admin`.
- O Admin não armazena painel nem API em cache offline.
- O login e as proteções atuais continuam iguais.

## Como instalar o Admin

1. Publique esta fase no Render.
2. No celular, abra diretamente:
   `https://portifolio-uama2027.onrender.com/admin`
3. Faça login normalmente.
4. Android/Chrome: toque em **Instalar Admin** quando aparecer.
5. iPhone/Safari: Compartilhar → **Adicionar à Tela de Início**.

O resultado será um segundo ícone chamado **UAMA Admin**, separado do app público.
