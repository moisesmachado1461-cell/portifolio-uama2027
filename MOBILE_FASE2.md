# UAMA — Fase Principal 2: Experiência Mobile

## Alterações incluídas

- Remoção completa da seção pública **Cronograma Geral / Programação dos 3 Dias**.
- Melhor espaçamento em telas pequenas.
- Botões e campos maiores para toque.
- Formulários com largura total no celular.
- Tabelas passam a rolar horizontalmente em vez de esmagar o conteúdo.
- Melhor tratamento de textos e protocolos longos.
- Ajustes para celulares compactos e aparelhos com área segura.

## Teste rápido

1. `npm.cmd run build`
2. `npm.cmd run dev`
3. Abra o site pelo modo responsivo do navegador ou pelo celular.
4. Confira:
   - a seção **Cronograma Geral** não aparece;
   - formulário cabe na tela;
   - botões são fáceis de tocar;
   - textos não ficam cortados;
   - `/admin` continua funcional.
